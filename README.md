# Parking-Fee-Calculator-project-
1. Project Introduction
The Parking Fee Calculator is a simple C++ program that calculates the parking charges based on the number of hours a vehicle is parked.
The user enters the vehicle type and parking hours. The program automatically calculates the total parking fee.
2. Objectives
- To calculate parking charges automatically.
- To reduce manual calculation.
- To make parking management easy.
- To understand basic C++ concepts.

3. C++ Concepts Used
1. Variables: Store vehicle choice, hours and fee.
2. If-Else: Select vehicle type and calculate charges.
3. Input (cin): Take information from the user.
4. Output (cout): Display parking details.
5. Operators: Multiply parking hours by hourly charges.

4. Advantages
- Easy to use.
- Saves time.
- Calculates parking fees automatically.
- Reduces calculation mistakes.

4. Conclusion
This project helps us understand the basic concepts of C++ programming. It provides an easy way to calculate parking fees according to vehicle type and parking duration.
